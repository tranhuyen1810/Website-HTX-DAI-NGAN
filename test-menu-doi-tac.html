✅ Menu Đối Tác - Hướng dẫn Test

👆 Di chuột vào menu "ĐỐI TÁC" ở header để xem mega menu!

🎯 Tính năng đã triển khai:

  • ✅ Mega Menu 4 cột - Hiển thị tất cả 4 nhóm đối tác cùng lúc
  • ✅ Hover to Show - Menu tự động hiện khi di chuột vào "ĐỐI TÁC"
  • ✅ Click to Navigate - Mỗi mục là link hợp lệ, click để điều hướng
  • ✅ Active State Detection - Tự động đánh dấu menu khi ở trang đối tác
  • ✅ Auto Open Dropdown - Dropdown tự động mở khi đang ở trang đối tác
  • ✅ Responsive Design - Tự động điều chỉnh trên mobile

1. Đối tác nông hộ & tổ hợp tác

🧪 Cách test:

  1. Test Mega Menu: Di chuột vào menu "ĐỐI TÁC" ở header
  2. Test Navigation: Click vào bất kỳ mục nào trong dropdown
  3. Test Active State: Sau khi vào trang đối tác, quay lại và xem menu "ĐỐI TÁC" được highlight
  4. Test Auto Open: Khi đang ở trang đối tác, dropdown sẽ tự động mở sẵn
  5. Test Responsive: Thu nhỏ cửa sổ browser để xem menu trên mobile

💡 Lưu ý kỹ thuật:

  • mega-menu class để tạo mega menu layout
  • mega-column class cho mỗi cột trong mega menu
  • active-page class tự động thêm khi ở trang đối tác
  • CSS transform để căn giữa mega menu
  • JavaScript auto-detect URL hiện tại
